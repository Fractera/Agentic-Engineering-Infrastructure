# `core/service-props/` — чем микросервис описывает сам себя

**Ядро сервера держит ТИП, службы держат ЗНАЧЕНИЯ, панель собирает КАРТУ.** Это решение владельца
2026-09-18: «где живут типы — base server core»; «каждый микросервис обязан импортировать типы,
согласно этим типам создать своё собственное описание, а наша новая функция должна забрать это
описание в себя».

| Файл | Что это |
|---|---|
| `service-props.decl.mjs` | **единственное объявление**: поля, закрытые роды, функция проверки `problemsOfProps` |
| `own-service-props.schema.json` | **порождено** — JSON Schema для проверки чужого файла |
| `own-service-props.ts` | **порождено** — тип для TypeScript-потребителей (панель) |
| `build.mjs` | порождает оба: `node core/service-props/build.mjs` |
| `check.mjs` | сторож: свежесть порождённого **и** негативный контроль самой проверки |

🔒 **ПОРОЖДАТЬ, А НЕ ПЕРЕЧИСЛЯТЬ.** Схема, написанная руками рядом с объявлением, — вторая правда:
она расходится молча и всегда в сторону «у меня проходит». Поэтому оба артефакта выходят из одного
файла, а `check.mjs` роняет проверку, если они отстали. Он же проверяет себя: восемь заведомо
испорченных описаний обязаны быть отвергнуты, правильное — пройти.

## Как это попадает в службу, которая лежит в ДРУГОМ репозитории

🛑 **Обычного `import` между ядром и службой не существует, и это измерено, а не предположено.**
Ядро (`ai-workspace`) клонируется в `/opt/fractera`; микросервисы приезжают отдельными
репозиториями в его подпапки. Локально это разные деревья, `workspaces` в ядре не заведены,
npm-пакета нет — на машине разработчика службы ядра может не быть вовсе.

Поэтому объявление **доезжает копией** с файлом происхождения и сторожем расхождения (подшаг 227-2),
как в проект входит любой чужой код. «Импортируй тип из ядра» буквально неисполнимо; исполнимо
«тип доезжает и сверяется».

## Что сюда НЕ входит и почему

**Свойства сервера, а не службы.** Кто стоит в корне домена, какие службы вообще установлены,
каким именем хост отвечает сейчас — это свойства **собранной карты**, и её хозяин панель. Служба,
объявившая себя корнем домена, объявила бы то, что решает не она.

**Ответ «где я стою сейчас».** Это `GET /v1/state` самой службы: имя хоста, протокол, защищено ли
соединение. Реестр говорит, **как задумано**; запрос — **как есть**; расхождение называется, а не
сглаживается.

## Версия

`PROPS_VERSION` в объявлении меняется вместе с набором полей — по ней сторож копии в чужом дереве
видит отставание.
